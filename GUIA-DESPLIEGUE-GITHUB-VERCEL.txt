## 🌐 **PASO A PASO - VERCEL**

### **Opción A: Conectar GitHub (Recomendado)**

#### **1. Crear Cuenta Vercel**
1. Ir a [vercel.com](https://vercel.com)
2. Sign up con GitHub (más fácil)
3. Autorizar Vercel para acceder a tus repositorios

#### **2. Importar Proyecto**
1. Dashboard Vercel → "Add New..." → "Project"
2. Buscar `ethnika-by-col` en tu GitHub
3. Seleccionar el repositorio
4. **Configuración Framework:**
   - **Framework Preset:** Vite (detectará automáticamente)
   - **Root Directory:** `./` (dejar por defecto)
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`

#### **3. Variables de Entorno (si aplica)**
```
# Generalmente no necesarias para este proyecto
NODE_ENV=production
```

#### **4. Desplegar**
1. Click "Deploy"
2. Esperar 2-3 minutos
3. ¡Listo! Tendrás URL: `https://ethnika-by-col.vercel.app`

### **Opción B: Despliegue Manual**

#### **1. Build Local**
```bash
# Build optimizado
npm run build

# Verificar carpeta dist
ls dist/
```

#### **2. Subir a Vercel CLI**
```bash
# Instalar Vercel CLI
npm i -g vercel

# Login
vercel login

# Desplegar
vercel --prod
```

## ⚠️ **PROBLEMAS COMUNES Y SOLUCIONES**

### **Problema 1: Imágenes no cargan**
```
Causa: Rutas incorrectas
Solución: Verificar que todas usen "/images/..."
```

### **Problema 2: Rutas no funcionan**
```
Causa: Configuración SPA
Solución: vercel.json ya configurado
```

### **Problema 3: Build falla**
```
Causa: Dependencias faltantes
Solución: npm install y revisar package.json
```

### **Problema 4: Sitio en blanco**
```
Causa: Error en build
Solución: Revisar logs de Vercel
```
